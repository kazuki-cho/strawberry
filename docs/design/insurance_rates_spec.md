# 保険料率・等級マスター管理画面 仕様書

## 1. 概要

本画面は、社会保険料の計算基礎となる「保険料率」および「標準報酬月額等級」を管理するためのマスターメンテナンス機能を提供する。

## 2. 機能要件

### 2.1. データ表示

- **画面初期表示**
    - データベースに登録されている最新の有効日のデータ（保険料率および等級表）をデフォルトで表示する。
    - 画面上部の「検索：タイトル」ドロップダウンには、登録済みのデータセットのタイトルが有効日の降順で一覧表示される。
- **データ切り替え**
    - 「検索：タイトル」ドロップダウンで任意のタイトルを選択すると、該当するデータセット（保険料率・等級表）が画面に表示される。

### 2.2. データ編集

ユーザーは以下の手順で既存のデータを編集できる。

1.  画面右上の「編集」ボタンをクリックする。
2.  画面が編集モードに切り替わり、各項目が入力可能になる。
3.  編集可能な項目は以下の通り。
    - **標準報酬月額等級表**
        - 等級表の有効日
        - 各等級の標準報酬月額
        - 各等級の報酬月額（下限・上限）
    - **保険料率**
        - 各保険種類の料率（%）
        - 各保険種類の有効年月日
4.  「保存」ボタンをクリックすると、変更内容がデータベースに保存される。
5.  「キャンセル」ボタンをクリックすると、変更内容が破棄され、閲覧モードに戻る。

### 2.3. データ新規作成

ユーザーは以下の手順で新しいデータセットを登録できる。

1.  画面右上の「新規作成」ボタンをクリックする。
2.  画面が新規作成モードに切り替わる。
3.  表示されているデータがコピーされ、各項目が入力可能になる。
4.  以下の項目を新規に設定する。
    - **タイトル**: 新しいデータセットを識別するための名称。
    - **等級表の有効日**: デフォルトで今日の日付が設定される。
    - **保険料率の有効年月日**: デフォルトで今日の日付が設定される。
5.  その他の項目を任意に編集する。
6.  「保存」ボタンをクリックすると、新しいデータセットとしてデータベースに登録される。

### 2.4. 保険種類管理

- **追加**
    - 編集モードまたは新規作成モード時、「保険種類を追加」ボタンが表示される。
    - ボタンをクリックするとダイアログが表示され、新しい保険種類名を入力して追加できる。
- **削除**
    - 編集モードまたは新規作成モード時、各保険料率の行に削除ボタンが表示される。
    - ボタンをクリックすると、確認ダイアログが表示された後、該当の保険種類がデータセットから削除される。

## 4. API仕様

### 4.1. データ取得 (GET /api/insurance-data)

- **機能**: 保険料率および等級表のデータを取得する。
- **リクエストパラメータ**: `title` (string, optional) - 取得したいデータセットのタイトル。省略した場合は最新のデータセットを取得。
- **レスポンス**: JSON形式で、以下の情報を含むオブジェクトを返す。
    - `available_titles`: 登録済みの全タイトルのリスト。
    - `selected_title`: 現在選択されているタイトル。
    - `grade_effective_date`: 等級表の有効日。
    - `compensation_grades`: 標準報酬月額等級表のデータリスト。
    - `insurance_rates`: 保険料率のデータリスト。

### 4.2. データ新規作成 (POST /api/insurance-data)

- **機能**: 新しい保険料率・等級表のデータセットを作成する。
- **リクエストボディ**: JSON形式で、画面で入力されたデータ一式を送信する。
- **レスポンス**: 成功メッセージ、またはエラーメッセージを返す。
- **バリデーション**: タイトル、等級表の有効日、保険料率、等級表データが必須。

### 4.3. データ更新 (PUT /api/insurance-data/<title>)

- **機能**: 既存の保険料率・等級表のデータセットを更新する。
- **リクエストURL**: `<title>` には更新対象のデータセットのタイトルを指定する。
- **リクエストボディ**: JSON形式で、画面で編集されたデータ一式を送信する。
- **レスポンス**: 成功メッセージ、またはエラーメッセージを返す。
- **バリデーション**: 等級表の有効日、保険料率、等級表データが必須。
